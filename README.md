# Tsiino Hiiwiida — site público

Este repositório contém **apenas o site já gerado** que é publicado em
**[tsiinohiiwiida.net](https://tsiinohiiwiida.net)** pelo GitHub Pages.

O **Tsiino Hiiwiida** é um projeto científico sobre a biodiversidade de plantas e fungos no
Alto Rio Negro, na região da Cabeça do Cachorro (São Gabriel da Cachoeira, Amazonas, Brasil).
O site reúne expedições botânicas, coleções científicas, um catálogo de espécies e um
[validador de planilhas de herbário](https://tsiinohiiwiida.net/ferramentas/validador-herbario/).

- Páginas: [Sobre](https://tsiinohiiwiida.net/) · [Expedições](https://tsiinohiiwiida.net/expedicoes/) · [Acesso aos dados](https://tsiinohiiwiida.net/acesso/) · [Equipe](https://tsiinohiiwiida.net/team/)
- Contato do projeto: tsiinohiiwiida@gmail.com

O código-fonte, os dados de trabalho e os scripts de geração ficam num repositório privado.
Este repositório é atualizado automaticamente a cada publicação, por isso não edite os arquivos aqui.
